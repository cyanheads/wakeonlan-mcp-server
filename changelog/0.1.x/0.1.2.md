# 0.1.2 — 2026-10-09

## Added

- **Docker image** — `ghcr.io/cyanheads/wakeonlan-mcp-server` for Linux `amd64` and `arm64`; it wakes hosts only under `--network host` or macvlan on a Linux machine attached to the LAN. Production dependencies install on the build platform, so the multi-arch build runs no JavaScript under QEMU (mcp-ts-core 0.13.10), and musl-only packages are pruned from the image (0.13.11). The README Docker section now pulls the published image; 0.1.1 shipped without one.
- **Request ID on tool errors** — error results carry `data.requestId`, and the content text closes with `request <id>` (mcp-ts-core 0.13.10, cyanheads/mcp-ts-core#576).

## Changed

- **`wol_list_reference` `sender-environment`** — the Containers note covers host and macvlan networking and Docker Desktop.
- **Null optional arguments** — a `null` sent for an optional argument such as `wait_for_s` is treated as absent and its default applies (mcp-ts-core 0.13.14).
- **`server.json`** — the npm entries drop the `run start:stdio` / `run start:http` package arguments and set `runtimeHint` `npx` (was `node`); the HTTP entry sets `MCP_TRANSPORT_TYPE` to `http` (mcp-ts-core 0.13.11, cyanheads/mcp-ts-core#622).
- **MCP SDK** — `@modelcontextprotocol/server` moves to ^2.2.0 through the framework; on stdio, stdin EOF now aborts requests still in flight (mcp-ts-core 0.13.9).
- **Package contents** — `Dockerfile` joins the npm package `files`; `.mcpbignore` also excludes `/Dockerfile`, `/.cache/`, `/coverage/`, and `/tests/` from the bundle.
- **Error recovery hints** — `wol_wake_host` and `wol_check_host` rely on the framework filling each declared `recovery`, instead of forwarding it themselves (internal; the wire output is unchanged).
- **CodeQL workflow** — one analysis job per language, uploading under `/language:<language>`.
- **Repo config** — `.dockerignore` excludes every `.env*` file and the MCP registry token files, `.gitignore` keeps `.env.template` and `.env.sample`, and `.env.example` documents `MCP_REQUEST_STATE_KEY` and `LOG_LLM_INTERACTIONS`. Framework scripts and `framework-skills/` are resynced to 0.13.14.
