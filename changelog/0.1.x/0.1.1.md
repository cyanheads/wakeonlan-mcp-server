# 0.1.1 — 2026-09-26

First public release. Four tools and no resources or prompts; every target is an operator-configured host profile addressed by alias, never a raw MAC, IP, or port.

## Added

- **`wol_wake_host`** — sends 3 magic packets to the host's subnet-directed broadcast, then polls its TCP check port every 2 s for up to `wait_for_s` (0–55, default 30); `state` reports `already_awake`, `awake`, `not_reachable`, or `unverified`, and a concurrent wake of the same host fails with `wake_in_progress`.
- **`wol_check_host`** — one TCP connect to the host's configured check port with a 1.5 s timeout, no packet sent; `outcome` is `open`, `refused`, or `no_answer`.
- **`wol_list_hosts`** — the configured profiles with effective `broadcast`, `broadcast_source`, and `on_segment` (whether this machine has an interface on the host's subnet); SecureOn passwords surface only as `secureon_set`.
- **`wol_list_reference`** — static notes by `topic`: `packet-format`, `prerequisites`, `sleep-states`, `troubleshooting`, `host-profiles`, `sender-environment`.
- **Host profiles** — `WOL_HOSTS_FILE` (absolute path, `~/` expanded, regular file of at most 1 MiB) or `WOL_HOSTS` (inline JSON), mutually exclusive and validated at startup; fields `alias`, `mac`, `address`, `broadcast`, `wol_port` (default 9), `check_port` (default 22), `secureon`, `description`.
- **HTTP exposure guard** — startup refuses an unauthenticated HTTP bind on a non-loopback host, and an unauthenticated loopback endpoint with `MCP_ALLOWED_ORIGINS=*`; `MCP_AUTH_MODE` `jwt` or `oauth` serves either. Session mode is `stateless`.
- **Packaging** — npm package `@cyanheads/wakeonlan-mcp-server`, MCP Registry `server.json` (stdio and HTTP), a `.mcpb` Claude Desktop bundle, and Claude Code and Codex plugin manifests. No Docker image: a bridge-networked container cannot send LAN broadcasts.

## Dependencies

- **`@cyanheads/mcp-ts-core`** ^0.13.8. Packet send, probes, and interface lookup use Node built-ins (`node:dgram`, `node:net`, `node:os`).
